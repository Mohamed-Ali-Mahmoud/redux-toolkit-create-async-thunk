"# redux-toolkit-create-async-thunk"

## front-end

This project is a front-end application that utilizes Redux Toolkit to manage state and handle asynchronous actions using `createAsyncThunk`.

### to run this project

change directory to the project folder and run the following commands:

1 - json-server

```bash
npm install
```

2 - front-end

```bash
npm install
```

change directory to the project folder and run the following commands:

1- json-server

```bash
npm start
```

2 - front-end

```bash
npm run dev
```
